##  Objetivo do Programa
O objetivo deste programa é disponibilizar uma calculadora interativa desenvolvida em fluxo de blocos no Flowgorithm. O sistema permite ao usuário selecionar e executar diversas operações matemáticas, conversões de unidades, cálculos geométricos e análises físicas por meio de um menu dinâmico de opções.

---

##  Descrição do Funcionamento
Ao executar o programa, um menu principal é exibido solicitando que o usuário escolha a operação desejada. O programa foi construído com o laço de repetição (`While`), permitindo realizar múltiplos cálculos dentro dos 20 disponíveis de forma contínua até que o usuário opte por encerrar a execução. O sistema lê os dados de entrada fornecidos, processa os cálculos correspondentes e exibe a saída formatada na tela.

---

##  Modularização
O código foi estruturado de forma inteiramente **modularizada**. A lógica de cada cálculo foi isolada em funções/módulos específicos e chamada no fluxo principal através do bloco **`Call`**, garantindo um código limpo, legível, organizado e de fácil manutenção.

---

##  Relação das 20 Funções Implementadas

### Funções Obrigatórias:
1. **Cálculo de IMC (Índice de Massa Corporal)** – Avalia o IMC com base no peso e na altura informados.
2. **Cálculo de Área do Retângulo** – Calcula a área de um retângulo com base na base e altura.
3. **Cálculo de Área do Círculo** – Calcula a área de um círculo com base no raio informando.
4. **Cálculo de Área do Triângulo** – Calcula a área de um triângulo a partir da base e altura.

### Operações Aritméticas e Matemáticas:
5. **Soma** – Adição de dois números.
6. **Subtração** – Subtração de dois números.
7. **Multiplicação** – Multiplicação de dois números.
8. **Divisão** – Divisão de dois números com tratamento para divisão por zero.
9. **Potenciação** – Elevação de uma base a um expoente.
10. **Raiz** – Cálculo da raiz quadrada de um número.
11. **Média Aritmética** – Cálculo da média entre valores informados.
12. **Porcentagem** – Cálculo do percentual de um determinado valor.
13. **Valor de Desconto** – Aplicação de percentual de desconto sobre um valor base.

### Geometria e Física:
14. **Comprimento da Circunferência** – Cálculo do perímetro do círculo com base no raio.
15. **Perímetro do Retângulo** – Soma dos lados de um retângulo.
16. **Teorema de Pitágoras** – Cálculo da hipotenusa a partir dos catetos.

### Conversões de Unidades e Medidas:
17. **Conversão de Celsius para Fahrenheit** – Conversão de unidades de temperatura (°F).
18. **Conversão de Fahrenheit para Celsius** – Conversão de unidades de temperatura (°C).
19. **Conversão de Dias para Horas** – Conversão de unidades de tempo (dias x 24).
20. **Conversão de Quilômetros para Milhas** – Conversão de unidades de distância.

##  Instruções Básicas para Execução

1. Faça o download e instale o software [Flowgorithm](http://www.flowgorithm.org/).
2. Baixe o arquivo `calculadora.fprg` presente nesta pasta do repositório.
3. Abra o arquivo `calculadora.fprg` no programa Flowgorithm.
4. Clique no botão **Executar** (ícone do "Play" verde) ou pressione a tecla **`F5`**.
5. Selecione a opção desejada no menu do console e insira os dados solicitados.
