# calculadora-flowgorithm
Sobre o Sistema: Calculadora com 20 operações distintas desenvolvida diretamente no Flowgorithm, variando entre operações aritméticas, matemática avançada, geometria plana, conversões de unidades e cálculos físicos. 
Funcionalidades: Construído com o laço de repetição (While), Permite realizar múltiplos cálculos dentre os 20 disponíveis até optar por sair.
Modularização: Organizado através do bloco "Call" e funções isoladas para manter o código limpo e de simples visualização.

COMO EXECUTAR: 
1. Faça o Download do [Flowgorithm]
2. Faça o Download do Arquivo '.fprg' presente neste repositório.
3. Abra o Arquivo no Flowgorithm e execute clicando no Botão 'Play' ( Ou pressione 'F5' ).
